# 🛠 Установка бота «с нуля» — подробная инструкция

Эта инструкция рассчитана на новичка. Схема простая: **бот устанавливается и работает на
вашем компьютере, а пишете вы ему в Telegram с iPhone.** Пока компьютер включён и программа
запущена — бот отвечает. Для работы 24/7 без включённого компьютера см. последний раздел.

> Всего 4 шага и ~20–30 минут. Идите строго по порядку и не пропускайте пункты.

---

## Шаг 1. Создаём бота в Telegram (делается на iPhone, 5 минут)

1. Откройте Telegram на телефоне, в поиске введите **@BotFather** (у него синяя галочка).
2. Нажмите **Start** и отправьте команду:
   ```
   /newbot
   ```
3. BotFather спросит **имя** бота (любое, например `Мой инвест-аналитик`).
4. Затем спросит **username** — он должен заканчиваться на `bot`, например `my_invest_analyst_bot`.
   Если занят — придумайте другой.
5. В ответ BotFather пришлёт строку вида:
   ```
   1234567890:AAExampleABCdefGHIjklMNOpqrsTUVwxyz12
   ```
   **Это ваш токен.** Скопируйте его и сохраните — понадобится на Шаге 3.
   ⚠️ Токен = пароль от бота. Никому не показывайте.

6. (Рекомендуется) Узнайте свой **Telegram ID**, чтобы только вы могли пользоваться ботом:
   найдите в поиске **@userinfobot**, нажмите Start — он пришлёт ваш `Id` (число, например `987654321`).
   Запишите его.

## Шаг 2. (Необязательно) Ключ Claude для умных сводок

Бот **работает и без этого**, просто новости будут показываться списком без ИИ-разбора.
Если хотите умные сводки и раздел «инвест-идеи» с анализом — получите ключ:

1. На компьютере откройте <https://console.anthropic.com/>, зарегистрируйтесь.
2. В разделе **Billing** привяжите способ оплаты (сервис платный, но для личного бота это
   копейки — обычно центы за сводку).
3. В разделе **API Keys** нажмите **Create Key**, скопируйте строку вида `sk-ant-...`.
   Сохраните — понадобится на Шаге 3.

> Нет возможности оплатить? Пропустите этот шаг. На Шаге 3 просто оставите строку с ключом пустой.

## Шаг 3. Устанавливаем бота на компьютер

Выберите свой раздел: **Windows** или **macOS**. Делайте всё по порядку.

### 🪟 Вариант A: Windows

**3A.1. Установите Python**
1. Откройте <https://www.python.org/downloads/> и нажмите жёлтую кнопку **Download Python**.
2. Запустите скачанный файл. **ВАЖНО:** на первом экране поставьте галочку
   ✅ **«Add python.exe to PATH»**, затем **Install Now**.
3. Проверка: нажмите `Win`, наберите **PowerShell**, откройте его и введите:
   ```powershell
   python --version
   ```
   Должна появиться строка вроде `Python 3.12.x`. Если пишет «не является командой» —
   переустановите Python, не забыв галочку из п. 2.

**3A.2. Установите Git**
1. Скачайте с <https://git-scm.com/download/win> (закачка начнётся сама), установите
   «Далее-Далее» со всеми настройками по умолчанию.
2. Проверка в PowerShell:
   ```powershell
   git --version
   ```

**3A.3. Скачайте код бота** (в том же окне PowerShell):
```powershell
cd $HOME\Desktop
git clone https://github.com/maksvelichkinsergeevich-design/ui-ux-pro-max-skill.git
cd ui-ux-pro-max-skill
git checkout claude/telegram-investment-bot-nsjvm8
cd investment-bot
```

**3A.4. Установите зависимости** (в изолированное окружение):
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
После `activate` в начале строки появится `(.venv)` — так и должно быть.
Установка займёт 1–3 минуты.

**3A.5. Создайте файл настроек `.env`:**
```powershell
copy .env.example .env
notepad .env
```
Откроется Блокнот. Заполните строки (вставьте свои значения после `=`, без кавычек и пробелов):
```
TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
ANTHROPIC_API_KEY=sk-ant-ваш_ключ        # или оставьте пустым: ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-sonnet-5
ALLOWED_USER_IDS=ваш_telegram_id         # число из @userinfobot; или оставьте пустым
DATABASE_PATH=investment_bot.db
TIMEZONE=Europe/Moscow
DAILY_DIGEST_TIME=09:30
```
Сохраните (**Файл → Сохранить**) и закройте Блокнот.

**3A.6. Запустите бота:**
```powershell
python run.py
```
Если увидите строку `Бот запущен. Ожидаю сообщения…` — всё готово! Переходите к Шагу 4.
**Не закрывайте это окно** — пока оно открыто, бот работает.

### 🍎 Вариант B: macOS

**3B.1. Установите Python**
1. Откройте <https://www.python.org/downloads/macos/>, скачайте свежий установщик
   (**macOS 64-bit universal2 installer**), установите двойным кликом «Далее-Далее».
2. Проверка: откройте **Терминал** (Cmd+Пробел → наберите «Терминал») и введите:
   ```bash
   python3 --version
   ```
   Должно быть `Python 3.12.x` (или другой 3.10+).

**3B.2. Установите Git**
- Введите в Терминале `git --version`. Если Git не установлен, macOS сам предложит
  установить «Command Line Developer Tools» — согласитесь и дождитесь окончания.

**3B.3. Скачайте код бота:**
```bash
cd ~/Desktop
git clone https://github.com/maksvelichkinsergeevich-design/ui-ux-pro-max-skill.git
cd ui-ux-pro-max-skill
git checkout claude/telegram-investment-bot-nsjvm8
cd investment-bot
```

**3B.4. Установите зависимости:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
В начале строки появится `(.venv)`. Установка — 1–3 минуты.

**3B.5. Создайте файл настроек `.env`:**
```bash
cp .env.example .env
nano .env
```
Откроется простой редактор. Заполните значения (стрелками двигайтесь по строкам):
```
TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
ANTHROPIC_API_KEY=sk-ant-ваш_ключ        # или оставьте пустым
ANTHROPIC_MODEL=claude-sonnet-5
ALLOWED_USER_IDS=ваш_telegram_id         # число из @userinfobot; или оставьте пустым
DATABASE_PATH=investment_bot.db
TIMEZONE=Europe/Moscow
DAILY_DIGEST_TIME=09:30
```
Сохранение в nano: **Ctrl+O**, затем **Enter**, выход — **Ctrl+X**.

**3B.6. Запустите бота:**
```bash
python3 run.py
```
Строка `Бот запущен. Ожидаю сообщения…` означает успех. **Не закрывайте окно Терминала.**

## Шаг 4. Проверяем на телефоне 🎉

1. Откройте Telegram на iPhone, в поиске введите **username вашего бота** (тот, что на `...bot`).
2. Нажмите **Start** или отправьте `/start`.
3. Попробуйте команды:
   ```
   /add SBER 10 250.5
   /portfolio
   /price GAZP
   /dividends SBER
   /ideas
   /help
   ```
Если бот отвечает — поздравляю, всё работает!

## Как запускать бота в следующий раз

Каждый раз, когда захотите включить бота, откройте терминал и выполните:

**Windows (PowerShell):**
```powershell
cd $HOME\Desktop\ui-ux-pro-max-skill\investment-bot
.venv\Scripts\activate
python run.py
```
**macOS (Терминал):**
```bash
cd ~/Desktop/ui-ux-pro-max-skill/investment-bot
source .venv/bin/activate
python3 run.py
```
Остановить бота — закрыть окно или нажать **Ctrl+C**.

## ❓ Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| `python` не является командой (Windows) | Не поставили галочку «Add to PATH». Переустановите Python с галочкой. Либо используйте `py` вместо `python`. |
| `command not found: python` (macOS) | Используйте `python3`, а не `python`. |
| `Не задан TELEGRAM_BOT_TOKEN` | Файл `.env` не заполнен или вы не в папке `investment-bot`. Проверьте токен в `.env`. |
| Бот не отвечает в Telegram | 1) Окно с `python run.py` должно быть открыто. 2) Проверьте, что написали правильному @username. 3) Токен в `.env` верный, без пробелов. |
| `⛔ Доступ ограничён` | Ваш ID не совпал с `ALLOWED_USER_IDS`. Впишите верный ID (из @userinfobot) или **оставьте поле пустым** — тогда доступ откроется. |
| Новости приходят списком, без ИИ-разбора | Не задан `ANTHROPIC_API_KEY`. Это нормально — либо добавьте ключ (Шаг 2), либо пользуйтесь так. |
| Ошибки при `pip install` | Обновите pip: `python -m pip install --upgrade pip` и повторите команду установки. |
| Не находит команду `/ideas`, `/bonds` | Не подтянулась свежая версия кода. В папке проекта выполните `git pull`, затем перезапустите бота. |

## 🔁 Хотите, чтобы бот работал 24/7 (без включённого компьютера)?

Тогда его нужно поставить на **арендованный сервер (VPS)** — это компьютер в дата-центре,
который никогда не выключается. Порядок такой же, как выше, плюс автозапуск через `systemd`.
Управлять сервером можно с iPhone через приложение **Termius** (SSH-клиент).

Стоит примерно 150–300 ₽/мес. Если решите — напишите мне «настрой 24/7 на сервере»,
и я подготовлю отдельную пошаговую инструкцию под вашего провайдера.
