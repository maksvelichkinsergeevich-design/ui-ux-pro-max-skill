# 📈 Инвестиционный аналитик — Telegram-бот (MOEX)

Персональный бот-помощник для инвестиционного счёта на **Московской бирже**. Ведёт учёт
покупок и продаж, считает статистику портфеля по текущим ценам, следит за дивидендами
и собирает **ИИ-сводку новостей** по вашим компаниям (через Claude API).

## Возможности

- 📊 **Портфель и статистика** — учёт сделок методом средней цены, бумажный и
  зафиксированный P/L, учёт комиссий, переоценка по текущим котировкам MOEX.
- 📈 **Графики** — распределение портфеля и P/L по позициям (PNG прямо в чат).
- 📥 **Импорт/экспорт** — выгрузка сделок в CSV и импорт из CSV/брокерского отчёта
  (терпим к русским заголовкам, `;` и запятой в числах).
- 💵 **Дивиденды** — предстоящие и прошедшие выплаты по бумагам из портфеля.
- 📰 **Новости по компаниям** — сбор из деловых RSS (РБК, Финам, Коммерсантъ,
  Интерфакс), фильтрация по вашим тикерам.
- 🧠 **Сводка новостей от ИИ** — Claude делает краткое деловое резюме: что произошло
  и как это может отразиться на бумаге.
- 💡 **Инвест-идеи (`/ideas`)** — скрининг ликвидных бумаг по динамике (моментум 1м/3м),
  дивидендной доходности и новостям; Claude ранжирует топ-идеи с тезисом и риском.
- 💵 **Облигации (`/bonds`)** — топ ОФЗ и корпоративных выпусков по доходности к погашению.
- 🗞 **`/digest`** — единая сводка: портфель + ближайшие дивиденды + новости.
- ⏰ **Ежедневная авторассылка** сводки в заданное время.
- 👁 **Список наблюдения** — следить за новостями по компаниям, которых ещё нет в портфеле.

## Быстрый старт

```bash
cd investment-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env       # заполните TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
python run.py
```

### Получение токенов

1. **Telegram-бот** — напишите [@BotFather](https://t.me/BotFather), команда `/newbot`,
   скопируйте токен в `TELEGRAM_BOT_TOKEN`.
2. **Claude API** — ключ на [console.anthropic.com](https://console.anthropic.com/),
   в `ANTHROPIC_API_KEY`. Без ключа бот работает, но новости выводит списком без ИИ-резюме.
3. **Свой Telegram ID** (для ограничения доступа) — узнать у [@userinfobot](https://t.me/userinfobot),
   вписать в `ALLOWED_USER_IDS` (через запятую). Пусто = доступ открыт всем.

## Команды

| Команда | Назначение |
|---|---|
| `/add ТИКЕР кол-во цена [комиссия] [ГГГГ-ММ-ДД]` | записать покупку |
| `/sell ТИКЕР кол-во цена [комиссия] [ГГГГ-ММ-ДД]` | записать продажу |
| `/portfolio` | статистика портфеля с текущими ценами |
| `/chart` | графики: распределение и P/L по позициям |
| `/trades [ТИКЕР]` | список сделок |
| `/del ID` | удалить сделку |
| `/export` | выгрузить сделки в CSV |
| `/import` | импорт сделок из CSV (прислать файл) |
| `/price ТИКЕР` | текущая котировка |
| `/dividends [ТИКЕР]` | дивиденды по бумаге или по всему портфелю |
| `/news [ТИКЕР]` | сводка новостей по компании или по портфелю |
| `/ideas [ТИКЕР ...]` | инвест-идеи по динамике, дивидендам и новостям |
| `/bonds [corp]` | топ облигаций по доходности (ОФЗ / корпоративные) |
| `/digest` | полная сводка |
| `/watch` / `/unwatch` / `/watchlist` | список наблюдения |

**Пример:** `/add SBER 10 250.5 5` — купил 10 акций Сбербанка по 250.5 ₽, комиссия 5 ₽.

## Как считается статистика

- Позиции агрегируются **методом средневзвешенной цены**.
- При продаже фиксируется прибыль/убыток `(цена продажи − средняя цена) × кол-во`.
- Открытые позиции переоцениваются по последней цене режима **TQBR** на MOEX.
- Показываются: вложено, текущая оценка, бумажный P/L (%), зафиксированный P/L, комиссии.

## Источники данных

- **Котировки и дивиденды** — [MOEX ISS API](https://iss.moex.com/iss/reference/)
  (публичный, без ключей).
- **Новости** — RSS деловых СМИ (настраиваются в `src/services/news.py`, список `FEEDS`).
- **Сводка** — Claude API (Anthropic).

Соответствие «тикер → ключевые слова» для новостей задано в `src/services/news.py`
(`TICKER_KEYWORDS`, ~30 крупнейших эмитентов). Названия остальных бумаг подтягиваются
с MOEX автоматически. Список легко расширить.

## Как работают инвест-идеи (`/ideas`)

1. Берётся вселенная ликвидных «голубых фишек» (или ваш список: `/ideas SBER GAZP LKOH`).
2. По каждой бумаге с MOEX собираются метрики: дневное изменение, **моментум** за ~1 и
   ~3 месяца (по дневным свечам), **дивидендная доходность** за 12 мес.
3. Предварительный отбор по эвристическому баллу (моментум + дивдоходность) даёт шорт-лист.
4. По шорт-листу подтягиваются свежие новости, и **Claude** ранжирует топ-идеи: тезис,
   на чём основан (конкретные метрики/факты) и ключевой риск.
5. Без `ANTHROPIC_API_KEY` выводится эвристический рейтинг без ИИ-разбора.

> ⚠️ Это аналитический инструмент, а не индивидуальная инвестиционная рекомендация.

## Формат импорта сделок (`/import`)

Пришлите боту CSV-файл. Минимально нужны колонки **тикер, количество, цена**; остальное
опционально. Понимаются русские и английские заголовки, разделители `,`/`;`/таб и запятая
как десятичный разделитель:

```
ticker,side,quantity,price,fee,date,note
SBER,BUY,10,250.5,5,2024-01-01,
GAZP,Продажа,5,150.5,3,2024-02-01,частичная фиксация
```

Образец в нужном формате всегда можно получить командой `/export`.

## Развёртывание

Бот работает через long-polling — достаточно любого хоста с Python 3.10+ и доступом в
интернет (VPS, домашний сервер, Raspberry Pi). Для постоянной работы оформите
`systemd`-сервис или запустите в Docker. База — файл SQLite (`DATABASE_PATH`),
не забудьте включить его в бэкапы.
